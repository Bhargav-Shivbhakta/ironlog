Move my data to a new Firebase project

One-time tool. It only reads from the old project and only writes to the new one. It never deletes anything, so the old project stays untouched as your backup. Nothing is sent anywhere except those two Firebase projects.

1 · Old project (where your data is now)

Pre-filled with the current project. Sign in with the email and password you use for the app.

2 · New project (where it should go)

In the new project: Authentication → turn on Email/Password; Firestore → create a database and paste the rules from MIGRATION.md. Then paste the new project's web-app config here.

3 · Names to copy

Browsers can't list empty "folders", so these names are spelled out. The defaults cover every app in this project.

4 · Run

Start with the check: it counts what would be copied and writes nothing.
